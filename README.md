# Vitor Barros · Portfólio

Dados, inteligência de mercado e automação aplicados à transformação de negócios.

**Site:** https://vitorbarros7.github.io/

Página única em HTML, CSS e JavaScript, sem dependências. O conteúdo (projetos, stack, trajetória e contatos) é gerado a partir de um arquivo de dados central e compilado em `index.html`.

Projetos corporativos são apresentados sem dados de clientes, pessoas ou valores internos. Os gráficos dos cards usam dados ilustrativos, sinalizados na tela.
